# Claude Code — Flashcards Harness

Antes de hacer trabajo de código, sigue el protocolo de lectura de `AGENTS.md`.

Reglas permanentes:

1. El usuario dirige el roadmap.
2. No inventes features ni decisiones de producto.
3. Una tarea a la vez.
4. `./init.sh` verde antes de editar.
5. Task + contract antes de implementar.
6. Arquitectura + convenciones antes de escribir código.
7. Lee documentación específica solo cuando sea relevante.
8. Cada acceptance necesita evidencia.
9. Implementer no se autoaprueba.
10. DONE requiere verification + reviewer + QA + final verde.

Fuentes de verdad:
- producto confirmado: `docs/PRODUCT.md`
- estado vivo: `progress/current.md`
- task: `.harness/tasks/`
- contract: `.harness/contracts/`
- Definition of Done: `CHECKPOINTS.md`
